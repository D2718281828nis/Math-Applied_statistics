## Дополнительные примеры

- **Extreme value theory.ipynb** — три типа предельных распределений (Гумбель, Фреше, Вейбулл) и семья GEV в сравнении с нормальным законом: хвосты, годовые максимумы на смоделированных временных рядах, уровни возврата («событие раз в 100 лет»), ЦПТ для сумм против теоремы Фишера–Типпета–Гнеденко для максимумов.
- **Fractal signals DFA Hurst.ipynb** — фрактальный гауссовский шум с разными показателями Хёрста, белый / розовый (1/f) / коричневый (1/f²) шум, метод DFA и спектр мощности; как отличить фрактальный процесс от белого шума с такой же нормальной гистограммой (ACF, агрегированная дисперсия, спектр, DFA, перемешанные суррогаты) и почему стандартный доверительный интервал для среднего на таких данных врёт.

Зависимости: `numpy`, `scipy`, `matplotlib`.
